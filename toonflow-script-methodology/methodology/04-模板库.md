# 模板库

> 💂 本页 = 剧本工作台的模板库。新建项目、建交接报告、出标准大纲时来本页复制对应模板。

> **给 Claude Code 的说明**：下面三套是 leon 在 Notion 里用的工作模板（项目工作页 / 交接报告 / 标准剧本大纲）。在 Toonflow 落地时，它们对应的是「项目工作区数据结构 / 阶段产物契约」——可作为数据模型与产式设计的参考，但具体字段 / 表结构一律以代码调研为准。

## 二、交接报告模板（冷启动简报）

> 维护规则：每个项目在项目记录页下建一份「交接报告（最新）」子页；**仅当用户要求时整页覆盖更新**，只维护一份最新版、不留历史。定位＝一屏速览的冷启动快照，让新窗口先读它即可接手；详细 canon 仍以工作页为准。

```markdown
# 工作交接报告（最新）

> 更新时间：YYYY-MM-DD HH:MM（时区）

## 一句话现状
（当前季 / 章 / 阶段，一句话说清现在到哪、下一步写什么）

## 冷启动必读（按顺序加载）
1. 本页（交接报告）
2. 项目工作页（控制台：规则 / 台账 / 已锁定事实 / 审计记录）
3. 当前承接章正文页（续写需接其结尾）
4. 当前季容器页
5. 标准剧本大纲页
6. 工作台规范页

## 进度快照
（各季 / 各章完成度，含审计分数与是否定稿）

## 上一步刚完成
（最近一次交付与回写动作）

## 下一步动作（具体）
（具体到写哪章 / 审计 / 修订 / 回写）

## 本章开工要点
（紧接的钩、章节功能、故事内时间、章末钩）

## 最容易踩的雷（精简版 · 详见工作页「已锁定事实」）
（体型 / 越阶 / 视角 / 金句 / 反派 / 送审上下文等最易翻车项，精简列点）

## 悬而未决 / 待决
（跨章待定项；无则写「暂无」）

## 如何继续
（新窗口一句话指令，如「读交接报告继续」）
```

### 标准剧本大纲写法规则
- **只写已锁定事实和明确规划**：不要把临时想法、审计争议、废稿内容写进标准大纲。
- **面向交付读者**：语言要比工作页更整洁，少写过程，多写结论。
- **保留创作依据**：每章的“笑点 / 爆点 / 现实映射”要能反推到 L1/L0，不做孤立梗。
- **状态必须明确**：已完成、待审计、待总修、待拆 L3、待写正文要分清。
- **不替代章节正文**：标准大纲只概括，不存放完整正文。
- **不替代接力规范**：标准大纲可以写接力说明，但真正的操作台账仍在项目工作页维护。
- **阶段性同步**：每完成一章、一季或一次总修，都要判断是否需要同步标准大纲。
