# SKILL：尼克儿童写手

- **一句话说明**：按风格指纹把 L3 beats 写成正文（少年/儿童向）。
- **类型**：写作

> ✍️ **能力（how、跨项目不变）**：拿架构师的 L3 outline，按**风格指纹**写成正文。

## 名称 / 版本 / 适用领域
- 名称：尼克儿童写手
- 版本：v1.0
- 适用领域：系列剧本创作工作台（逐章正文创作）

## 触发词
- 「用尼克写故事」「写第 N 章正文」

## 输入依赖（WORK 输入）
- 当章 L3 beats
- 主 / 辅风格指纹（风格库 + 项目专属规则）
- 已锁定事实与前序正文（接续写时接上一章结尾）
- 故事内时间与体型 / 物理约束

## 执行步骤
1. 接上一章事件 / 情绪 / 道具 / 时间
2. 按 beats 串行写当章正文，遵 5 条铁律（动作替说教 / 配角有反对声 / 坏得有理由 / 实物道具 / 卑微感不洗太快）
3. 保持 7 条风格指纹（短句≥60%、对话≥6%、句尾呀啦嘛、每章≥1 个被笑瞬间等）
4. 交双审计，根据 P0 在当页修订

## 输出契约
- 单章正文页（归入当季容器页）；符合主风格指纹；**无元叙事**（无“第几章 / 上一章 / 读者”）；同章修订不新建 v2/v3

## 校验清单（交审查子 Agent）
- 每章完成后派**结构审计 + 风格审计**（见审计规范 §B / §C），两路均无 P0 才算通过

## 反模式 / 禁止项
- 元叙事穿帮；作者旁白说教；金句强塞 / 越阶提前点题；核心字滥用升格；情绪词定式套话；功能性道具强行加戏；体型 / 物理动作漂移；奇观写成空响
