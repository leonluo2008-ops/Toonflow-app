# 创作方法论（写作铁律）

> 🎨 **本页 = 写正文时的创作铁律。** 逐章写作与修订时读本页；这些也是结构 / 风格审计的对照依据。

## 时间线管控规范（强制）

- **每章必须标注故事内时间**：第几日 · 时段（晨／午／黄昏／夜）· 距上章间隔（无缝紧接 / 隔 N 天）。在项目工作页维护一份「故事内时间线」（当前正文台账加列或单列时间表均可）。
- **逐章结构审计即查时间线**，不留到全季一致性审计才暴露：事件链（“紧接上一章”）与模糊时间词（“这些天 / 这两天 / 练出的本事”）必须自洽——半天的连续动作里不能冒出“过了好几天”的措辞，反之亦然。
- **跨章压缩或留白都要显式交代**：要么写明“打那以后过了好几天”，要么保持连续；不得让读者算不清到底过了多久。
- **回写**：每章定稿即把该章故事内时间写进时间线，与接力规范、台账同步。

## 角色 / 物种物理约束规范（强制）

- **体型先锁，动作后写**：主要角色、异兽、机器人、载具等一旦在正文或设定中出现明确体型（如“小马驹量级”“成人高”“巴掌大”），后续动作必须受该体型约束。
- **互动动作要过物理校验**：抱起、拖拽、背负、骑乘、钻缝、翻滚、并肩跑、挡刀、撞门等动作，必须符合双方体型、力量、受伤状态和场景空间；不能把小马驹写成猫狗，把巨兽写成玩偶。
- **修订时锁进台账**：一旦发现体型 / 物理动作冲突，应同时修正文稿、项目已锁定事实、章节台账和送审上下文，防止后续复发。

## 点题 / 金句 / 奇观机制方法论（强制）

- **金句宁缺毋滥**：金句是锦上添花 / 画龙点睛，不是 KPI。若会打断追逐、对抗、逃生、情绪崩溃等戏剧节奏，宁可不要台词金句；点题必须从戏里长出来，不能为了“本章有金句”让人物停下来讲道理。
- **事件优先点题**：优先用人物选择、行动代价、机制后果、反派失败方式证明主题；台词只在人物当下确实会说、且不抢戏时出现。
- **奇观必须推动因果**：神兽、异能、科技、魔法、系统等奇观不能只做音效/光效/热闹背景，必须改变环境、改变选择、制造阻力或推动解决；只“吼”“闪”“炸”但不改变局势，视为表层奇观。
- **本性复流法**：适用于神话 / 奇幻 / 科幻等设定型项目。先找出角色或物种被压制的“本性 / 功能 / 生态位”，再让主角通过理解找到压口，轻拨触发，使本性回流并改变局势。主角不是把对象当工具操控，而是让其回到原本是什么。
- **反派不降智**：反派必须按自身职业逻辑和资源做出合理反应；失败应来自世界观机制 / 价值观局限 / 系统性脆弱，而不是突然乖、突然傻、突然站着聊天。
- **情绪 / 反应去定式（语言分寸）**：某种情绪词（如「怕 / 恐惧」）一旦成为反复套话（如「（看 / 观）它怕什么」），会把角色或对象框成「单一内核」，显做作、损立意。改法：用动作呈现情绪 / 反应（炸毛、夹尾、嗥鸣、攒拳、别过脸）而非贴标签；同一情绪 / 认知动作的表述要多样化（性子 / 门道 / 破绽 / 伤处 / 怎么使劲 / 为什么挣…）；真实强情绪全篇少而精，宁留一两处真的，不让它泛滥成口头禅。
- **功能性道具节制（语言分寸）**：道具只在真正发挥功能（记、查、用）时出场；删「描出—塞回—攒紧—反复强调（湿 / 旧）」式无功能加戏；区分「核心道具」与「配角道具」，避免功能重叠把核心道具稀释（如纸质笔记本 vs 核心异能道具）；显然无法使用的混乱场景（坠落、逃命）不强行让角色摆弄道具。
- **正常语境优先于体系升格（核心字自然度）**：当创作体系要求把某个核心字 / 母题词升格（如把「看」升格成「观」）时，**正常语境＝最高优先级，高于体系升格**——日常视线 / 叙述一律用自然说法，核心字只在极个别真正高光的瞬间出现、全季配额宁缺毋滥；不为「兑现体系」强行升格，否则行文文绉绉、出戏。
